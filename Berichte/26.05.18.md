## Übung (Directory Permissions und Octal Notation)

### Oktale Umwandlung
Hier muss man für folgende Rechtssetzungen den "chmod" Befehl und die Oktal-Werte angeben

|Recht|Befehl|Oktal-Wert|
|-----|------|----------|
|rwxr-xr-x|chmod 755 <file>|u = 0x07, g = 0x05, o = 0x05|
|rw-rw----|chmod 660 <file>|u = 0x06, g = 0x06, o = 0x00|
|rwx------|chmod 700 <file>|u = 0x07, g = 0x00, o = 0x00|

### Pub-Verzeichnis
Nun soll man das Verzeichnis "/home/kali/pub" erstellen und die Rechte so einstellen, 
dass der User alles darf (7), die Gruppe "read" und "execute" darf (5) und die others nur "execute" darf (1)

**Befehl:**
```sh
$ mkdir /home/kali/pub 
$ chmod 751 /home/kali/pub
```

### Recursive Lockdown
Das Verzeichnis "" soll für die Gruppe "music" rekursiv lesbar gemacht werden, während others gar keinen Zugriff haben dürfen.

**Befehl:**
```sh
$ chown -R :music /tmp/lab/drafts
$ chmod g+rw, o-rwx /tmp/lab/drafts
```

### Search Permission
Nun soll man others nur noch das Recht geben, in die Unterverzeichnisse von "/home/kali" wechseln zu dürfen.

**Befehl:**
```sh
$ chmod o-rw,o+x /home/kali
```

### Analyse 
Jetzt soll man analysieren, warum nach der Eingabe des Befehls "chmod -R 660 /tmp/lab/" 
die User nicht mehr in Unterverzeichnisse wechseln können. Der Grund ist, dass beim User 
der Oktalwert 0x06 ist und dabei das "execute" Bit nicht gesetzt ist. Damit es für den User möglich wäre,
müsste das "execute" Bit gesetzt sein.

## Übung (Webserver Directory Permissions)
Nun soll man den others die "read" Berechtigung über "var/www" entziehen und danach
das "read" Bit setzen und das "execute" Bit rücksetzen. Dann soll man die Möglichkeiten analysieren.

**Befehl:**
```sh
$ sudo chmod o-r /var/www
```

Nach dem Befehl ist das Betreten des Files dadurch, dass das "execute" Bit gesetzt ist noch möglich, 
jedoch kann man den Inhalt mit "ls" nicht mehr auslesen, da das "read" Bit nicht mehr gesetzt ist. 
Wenn man den Namen des "HTML" kennt, kann man dahin wechseln.

**Befehl:**
```sh
$ sudo chmod o+r,o-x /var/www
```
Nun kann man nicht mehr in die Verzeichnisse wechseln, jedoch kann man sie mit "ls" ausgeben.
